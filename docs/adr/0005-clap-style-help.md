# Help pages use clap's own layout

Help pages use clap's layout (tagline, `Usage:`, `Arguments:`, `Options:`, then extra sections such as `Examples:` in the long help), styled through clap's `Styles`. This reverses [ADR 0002](0002-man-page-help-layout.md), which chose a man-page layout. We switched because the commands are already built with clap: its help is generated from the same definitions that parse the command line, so help cannot drift from behaviour, and clap's own error messages print a `Usage:` line that matches the help page exactly. A man-page layout would have needed a custom renderer and a `--help` override in every binary, and would still have clashed with clap's errors. If real man pages are wanted, generate them from the clap definitions (for example with `clap_mangen`) rather than writing a second layout. See [STYLE.md](../STYLE.md#help-pages).
